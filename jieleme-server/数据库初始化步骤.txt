========================================
  戒了么服务端 - 数据库初始化步骤
========================================

【重要】请按以下步骤操作：

步骤 1: 打开 MySQL 客户端工具
----------------------------------------
推荐使用以下任一工具：
□ MySQL Workbench（官方工具）
□ Navicat for MySQL
□ HeidiSQL
□ DBeaver
□ phpMyAdmin

如果没有安装，推荐下载 MySQL Workbench：
https://dev.mysql.com/downloads/workbench/


步骤 2: 连接到 MySQL
----------------------------------------
连接信息：
- Host: localhost (或 127.0.0.1)
- Port: 3306
- Username: root
- Password: root（或你的实际密码）


步骤 3: 执行初始化脚本
----------------------------------------
方式 A（推荐）：
1. 在 MySQL 客户端中，选择 "打开 SQL 文件" 或 "Execute SQL File"
2. 选择文件：init-database.sql
3. 点击"执行"或"运行"按钮

方式 B：
1. 打开 init-database.sql 文件（用记事本或编辑器）
2. 复制所有内容
3. 在 MySQL 客户端的查询窗口粘贴
4. 点击"执行"


步骤 4: 验证创建成功
----------------------------------------
执行以下 SQL 查询：

-- 查看数据库
SHOW DATABASES LIKE 'jieleme';

-- 切换到数据库
USE jieleme;

-- 查看表
SHOW TABLES;

预期结果：
应该看到两个表：
✓ t_user
✓ t_sms_code


步骤 5: 修改密码配置（如果需要）
----------------------------------------
如果你的 MySQL 密码不是 "root"：

1. 打开文件：src\main\resources\application.yml
2. 找到这一行：
   password: root
3. 改成你的实际密码：
   password: 你的密码


步骤 6: 启动服务
----------------------------------------
现在可以启动 Spring Boot 服务了！
